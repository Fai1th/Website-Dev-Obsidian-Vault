# Security policy

This repository distributes reference material and a pinned upstream code snapshot. It does not run a hosted application or certify that copied components are secure.

For a suspected exposed credential or a vulnerability in this repository, use GitHub's private **Report a vulnerability** option if the repository owner has enabled it. If it is unavailable, do not post secrets or exploit details publicly; ask the maintainer for a private reporting channel without disclosing sensitive details. No response-time promise is made.

For a vulnerability in an upstream library, follow that project's security policy and advisories. Updating this archive does not update copies already integrated elsewhere.

Treat source, registry commands and linked content as untrusted input. Review dependencies, licenses and install scripts in the target project. Run only checks appropriate to systems you own or are authorized to test. The repository validator checks content structure and selected patterns; it is not a complete security scanner.
