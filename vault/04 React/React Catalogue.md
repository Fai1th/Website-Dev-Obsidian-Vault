# React Catalogue

**61 actual React component source files + 24 usage examples** from shadcn/ui are bundled offline. They are unmodified and pinned to commit `4aaea19d9cff3e0908e12a8c1d504b8c5ec34610`. They are source references requiring project integration, not a ready-installed application.

Start with [Source Adoption](Source%20Adoption.md). Browse [Component Index](Component%20Index.md) for individual elements. Browse [React Library Index](React%20Library%20Index.md) for alternatives and specialist tools. The libraries are candidates for professional work; none is a blanket production-readiness guarantee.

## Choose by need

- Brand-owned UI: [shadcn UI](Libraries/shadcn%20UI.md), [Radix Primitives](Libraries/Radix%20Primitives.md), [Base UI](Libraries/Base%20UI.md), [React Aria](Libraries/React%20Aria.md), [Headless UI](Libraries/Headless%20UI.md).
- Application suites: [Mantine](Libraries/Mantine.md), [Material UI](Libraries/Material%20UI.md), [Fluent UI](Libraries/Fluent%20UI.md), [Carbon](Libraries/Carbon.md), [Primer React](Libraries/Primer%20React.md).
- Forms/data: [React Hook Form](Libraries/React%20Hook%20Form.md), [Zod](Libraries/Zod.md), [TanStack Table](Libraries/TanStack%20Table.md), [TanStack Virtual](Libraries/TanStack%20Virtual.md), [Recharts](Libraries/Recharts.md), [React Dropzone](Libraries/React%20Dropzone.md).
- Drawers/feedback: [Vaul](Libraries/Vaul.md), [Sonner](Libraries/Sonner.md).
- Optional motion: [Motion](Libraries/Motion.md), [Motion Primitives](Libraries/Motion%20Primitives.md), [Magic UI](Libraries/Magic%20UI.md).
- Dashboard references: [Tremor](Libraries/Tremor.md).

Use one primary foundation. Do not install every library. Visual registries are optional inspiration and require stronger review for interaction, motion, dependency and accessibility risks. The official [shadcn registry directory](https://ui.shadcn.com/docs/directory) is a discovery source, not automatic trust.

## Retrieval

Read one card, then the relevant source and optional example. Raw files are under `90 Sources/React Snapshot`; hashes and imports are in `manifest.json`. Mainstream components and specialist helpers are labeled separately. Some source defaults conflict with the library defaults and require adaptation.
