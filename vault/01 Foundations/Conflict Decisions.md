# Conflict Decisions

These decisions distinguish project preferences from technical requirements. See [Source Provenance](../90%20Sources/Source%20Provenance.md).

| Conflict | Resolution |
|---|---|
| Secondary text permitted at 3:1 in UI checklist | Normal-sized text uses 4.5:1. Large-text exceptions use the standard's size/weight definition. |
| Touch targets described as a universal 44px WCAG rule | Library preference is 44px. WCAG 2.2 AA target-size criterion is 24px with exceptions. |
| Cards, purple, serif or centered heroes banned by default | Avoid automatic use. Allow a documented brand, task or system reason. |
| Different CTA labels for one intent | Use a consistent label. Repeated placements of that action remain allowed. |
| Invent organic-looking mock metrics | All invented data is explicitly sample data. Plausibility does not make it evidence. |
| Always generate images / minimum image quota | Prefer authentic content and relevant assets. No arbitrary photo quota. |
| Hero must fit viewport | Aim for clarity on ordinary screens; text resize and reflow take priority over a rigid fit. |
| Serif described as editorial default elsewhere | Choose only when justified by this brand; sans is the general starting point. |
| Global dark-mode demand | Support themes required by the brief/system and test all supported modes. Do not add a gratuitous toggle. |
| No repeated layout family | Applies to marketing rhythm. Repeated records and product UI stay consistent. |
| Registry uses Lucide; taste skill prefers other icons | Preserve upstream snapshot. Adapt to the project's one chosen icon family after reviewing semantics. |
| Upstream button uses small dimensions / transition-all | Adapt target size and motion before project adoption. Source is not certified compliant. |

Technical basis: [Accessibility Rules](../06%20Quality/Accessibility%20Rules.md), [Motion Rules](Motion%20Rules.md), [Content and Evidence](Content%20and%20Evidence.md). Aesthetic similarity is not proof of AI authorship.
