# Images and Asset Rights

Choose assets for the actual subject: approved brand photography, real product screenshots, case-study work or commissioned illustrations. Use generated images only when they fit the brief and are represented honestly. A synthetic image is not evidence of a real customer's result.

Pinterest, Behance, Dribbble and Instagram are discovery channels. A visible image is not a reusable license. Record creator, original URL, usage permission and any attribution requirements. Never assume a stock placeholder can ship unchanged.

For product previews, prefer a real captured screen or a functioning demonstration. Label simulated data. Avoid fake application rectangles that imply unsupported behavior.

Set responsive sources, useful alt text, intrinsic dimensions and an intentional crop/focal point. Decorative assets can use empty alt text. Do not put essential copy inside an image without an accessible equivalent.

Keep an asset ledger: filename, source, license, permission, intended placement, crop and expiry if applicable. Keep credential-bearing URLs out of notes.

Professional exception: a content-first service or documentation page can be text-led without arbitrary stock photography. Assets must serve a purpose; an image quota is not a quality metric.
