# Dark Accent Profile

An optional example for a technical brand with a dark identity. This is a generic sample profile, not a private brand specification.

Use a near-black canvas, clear warm-white text, restrained charcoal surfaces and one deliberate accent. Lavender or another violet can fit when chosen by the actual brand. It is not the automatic colour for every software product.

Use subtle borders and limited depth. Blur and grain are optional; provide solid backgrounds where needed and avoid continuous decorative effects on low-powered devices. Respect reduced motion.

Measure the final foreground/background combinations and focus indicators. Keep product data, code and controls readable. Record selected tokens, source rights and theme support in the project manifest.
