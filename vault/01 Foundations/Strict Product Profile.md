# Strict Product Profile

An optional example for restrained, task-heavy products. This is a reusable sample profile, not an imported private project configuration. Apply it only when selected by the project brief.

- At most two font families; body measure up to about 65 characters.
- Bold emphasis; reserve underlines for links.
- One neutral family and one decorative accent; semantic status colours stay distinct.
- Visible keyboard focus and a preferred 44px minimum touch target.
- Small transform/opacity transitions under 300ms; frequent operations can be immediate.
- Respect reduced motion and keep state understandable without animation.
- Use one focal point per screen and a documented spacing scale.
- Review imported components for smaller targets, broad transitions and inaccessible state.

Record actual tokens and exceptions in the [Project Brief Template](../09%20Templates/Project%20Brief%20Template.md). The [Accessibility Rules](../06%20Quality/Accessibility%20Rules.md) and relevant security controls still apply.
