# START HERE

This is a reusable web design library for people and coding agents. Use the small core and select notes by task. This is durable external knowledge; it does not automatically expand an agent's context window or guarantee a token saving.

## Use it

1. For an agent: read [AGENT START](AGENT%20START.md) and [Core Design Rules](01%20Foundations/Core%20Design%20Rules.md).
2. Pick one genre in [Design Genres](02%20Genres/Design%20Genres.md) and one page structure in [Page Structures](03%20UI/Page%20Structures.md).
3. For React, choose a foundation in [React Catalogue](04%20React/React%20Catalogue.md), then open only the relevant component cards.
4. Before shipping, use [Professional Release Checklist](06%20Quality/Professional%20Release%20Checklist.md) and the applicable [Security Map](05%20Security/Security%20Map.md).
5. Save the project's selected notes and decisions with [Project Brief Template](09%20Templates/Project%20Brief%20Template.md). Save durable lessons with [Lesson Template](09%20Templates/Lesson%20Template.md).

## Browse

- [Foundations](01%20Foundations/Foundations.md): type, colour, layout, content, assets and motion.
- [Design Genres](02%20Genres/Design%20Genres.md): eleven directions and their exceptions.
- [UI Patterns](03%20UI/UI%20Patterns.md): page structures, forms, navigation, state and data patterns.
- [React Catalogue](04%20React/React%20Catalogue.md): actual offline source, examples and upstream alternatives.
- [Security Map](05%20Security/Security%20Map.md): implementation controls and negative checks.
- [Quality Map](06%20Quality/Quality%20Map.md): accessibility, responsive behavior, performance and release evidence.
- [Build Workflow](07%20Workflows/Build%20Workflow.md): repeat the process, preserve decisions, verify results.
- [Inspiration Index](08%20Inspiration/Inspiration%20Index.md): reviewed production sites and social discovery leads.
- [Research Ledger](90%20Sources/Research%20Ledger.md): what was accessible, blocked, or only partially inspected.
- [Source Provenance](90%20Sources/Source%20Provenance.md) and [Conflict Decisions](01%20Foundations/Conflict%20Decisions.md): where rules came from and how conflicts were settled.

## Open as an Obsidian vault

In Obsidian, choose **Open folder as vault** and select the downloaded or cloned `vault` folder. The vault uses built-in Markdown, backlinks, tags and Templates. Community plugins are not required. Search works with ordinary filesystem tools too.

The `90 Sources/React Snapshot` directory contains unmodified third-party code. Its files are integration references, not a configured application. Start with [Source Adoption](04%20React/Source%20Adoption.md) before copying code.
