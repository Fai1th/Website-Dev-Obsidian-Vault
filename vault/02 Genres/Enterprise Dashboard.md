# Enterprise Dashboard

Best for: Business applications, admin tools, analytics.

Intent: Fast repeatable tasks and legible data.

## Page structure

App shell > page title/actions > filters > summary when useful > primary table/chart > details panel.

## Rules

Use a real component system aligned to the product ecosystem. Keep density, column alignment, keyboard access and task state consistent. Use tabular figures, explicit units and permission-aware actions.

## Professional exception

Neutral fonts, repeated cards and highly regular rows are professional here. A marketing novelty rule does not justify disrupting learned workflows.

## Avoid

Avoid decorative gradient metrics, unlabeled icons, hiding key columns on mobile and dashboards filled with invented precision.

## Mobile and validation

Provide scoped table scrolling or a deliberate record view. Preserve sort/filter state in URLs where practical. Do not hide essential operations behind hover.
