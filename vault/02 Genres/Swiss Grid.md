# Swiss Grid

Best for: Architecture, cultural programmes, factual brand systems.

Intent: Clear hierarchy through alignment, scale and deliberate grid tension.

## Page structure

Identity header > strong statement > modular work index > factual detail > contact.

## Rules

Build a visible alignment system. Let typography and real images establish hierarchy. Use restrained colour, precise column relationships and consistent metadata. Preserve logical reading order when desktop alignment is asymmetric.

## Professional exception

A grid line or index number is allowed when it organizes actual content. It must do more than signal that the site was designed.

## Avoid

Avoid crosshair decoration, arbitrary rotated text and walls of micro-caps that make every section look identical.

## Mobile and validation

Recompose rather than shrinking the desktop grid. Keep labels near their content and avoid reordering only visually.
