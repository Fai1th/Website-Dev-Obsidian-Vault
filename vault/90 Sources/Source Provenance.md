# Source Provenance

## Original guidance

The concise rules, genre recipes, workflows and templates in this public edition are an opinionated curation. Personal machine paths, private project identities, deployment permissions and full local skill archives have been excluded. The two sample profiles are generic examples, not evidence of a tested product.

Design preferences are not universal standards or a detector of AI authorship. Technical guidance is attributed near the relevant claim. [Conflict Decisions](../01%20Foundations/Conflict%20Decisions.md) explains important distinctions, including text contrast, target sizes, viewport fitting and professional exceptions.

## Technical sources

- Security: the linked [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) and [ASVS](https://owasp.org/www-project-application-security-verification-standard/).
- Accessibility: linked [W3C WCAG 2.2 guidance](https://www.w3.org/WAI/WCAG22/quickref/) and ARIA Authoring Practices.
- Performance: linked [web.dev Web Vitals](https://web.dev/articles/vitals).
- React: official library documentation, public repository metadata and the pinned shadcn/ui source described in [Source Adoption](../04%20React/Source%20Adoption.md).

External documentation is referenced and briefly summarized, not relicensed by this project. Third-party code keeps its original license and copyright; see the repository's THIRD_PARTY_NOTICES.md and the snapshot license.

## Inspiration and evidence

Every inspiration note states whether it was visually inspected, read as text, found only in search metadata or blocked. [Research Ledger](Research%20Ledger.md) records the limits. No image reuse rights, conversion gains, security certification or human-only authorship are inferred.

Evidence levels: candidate, observed, catalogued, source-snapshot, integrated, tested and deprecated. Only promote status when the named checks were actually performed. Record source URL, version/commit, date, scope and unresolved limitations.
