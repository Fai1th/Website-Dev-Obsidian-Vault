# Marketing Sections

Build each section around a real content job. A split hero needs a strong message and a meaningful asset; an editorial hero needs a message worth reading. A bento needs unequal content importance, not empty tiles.

Vary page rhythm through scale, alignment, asset type and content density. Avoid three consecutive image/text zigzags and repeating the same feature-card layout for unrelated sections. Do not add random forms solely to manufacture variation.

Keep hero copy short, with one primary action and at most one useful secondary action. Trust evidence can follow in a separate section. Use proof only when permission and claims are verified.

FAQs answer actual uncertainty. Pricing comparisons disclose billing basis and material limits. Case studies explain problem, contribution and evidence. Contact sections explain what happens next.

For every block define content, asset, action, mobile fallback, theme tokens and reduced-motion behavior. Build a real functioning product demo only when it represents supported behavior. Do not create fake product evidence with decorative code.
