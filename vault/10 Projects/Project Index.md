# Project Index

Keep private project manifests outside a public fork unless you intentionally want to share them. The repository ignores a dedicated `10 Projects/Private` folder by default; `.gitignore` is not a substitute for reviewing staged files.

Start with [Project Brief Template](../09%20Templates/Project%20Brief%20Template.md). See [Example Project Manifest](Example%20Project%20Manifest.md) for a filled, fictional example. Save reusable decisions with [Lesson Template](../09%20Templates/Lesson%20Template.md), without customer data or credentials.
