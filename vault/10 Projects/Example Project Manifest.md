# Example Project Manifest

Status: fictional planning example. No application was built or tested for this example.

## Brief

Project: an independent architecture studio portfolio. Audience: prospective clients. Primary task: inspect relevant work and send a qualified enquiry. Existing stack: record the real installed framework and versions before implementation.

## Design decisions

One sans-serif family, one accent, real approved project photographs, visible focus and a shared spacing/radius scale. Mobile order: project image, project title, role/description, action. Photo rights and credits must be recorded before release.

Exception candidate: a centered opening statement may fit a concise studio identity. Validate it against real content and mobile layout rather than accepting it automatically.

## Verification plan

Not yet executed: validate submission success/failure/retry, keyboard navigation, narrow layout, zoom, contrast, source rights and repository build checks. Record actual commands, dates and limitations when work is done. Do not convert this plan into a tested claim.
