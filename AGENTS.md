# Repository guidance

For web-design reference work, read `vault/AGENT START.md`, then the core rules and only the relevant genre, UI, component and security notes. Do not bulk-load the vault or source archive.

When editing this repository, preserve attribution, status boundaries and exact third-party source bytes. Use standard relative Markdown links. Keep private project content and machine-specific settings out of commits. Run `python scripts/validate.py` before publishing. Record substantive changes in CHANGELOG.md.

The snapshot is a reference collection, not an installable React application. No root build/package install is required. Do not execute upstream source merely to inspect it. The user's current request and applicable project instructions take precedence over library preferences.
