# Contributing

Improve a reusable decision, source record or verification step. Prefer a concise, inspectable contribution to an unreviewed collection of links.

1. Read the relevant note and its sources. Follow the [curation rubric](vault/07%20Workflows/Curation%20Rubric.md).
2. Identify scope: technical requirement, design preference, generic example or project-validated lesson.
3. Add canonical attribution, inspection date, rights and evidence limits. Do not infer accessibility, conversion, security or AI authorship from an image.
4. Use standard relative Markdown links so GitHub and Obsidian can both navigate the notes.
5. Run `python scripts/validate.py`. Include the result and manual review details in the pull request.
6. Add substantive changes to CHANGELOG.md. Keep counts and visual assets accurate.

Do not submit credentials, private client data, personal workspace settings, unlicensed screenshots or embedded instructions from third-party content. Keep the pinned React source unmodified. For a deliberate refresh, update source, examples, manifest, license and cards together; follow [Versioning and Updates](vault/07%20Workflows/Versioning%20and%20Updates.md).

Useful contributions: an original pattern with explicit mobile/state rules; a corrected technical statement backed by primary documentation; a verified creator trail; or a source-adoption lesson with named version and test evidence.
